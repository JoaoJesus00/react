# React Estudos

Interface web desenvolvida com React e TypeScript, integrada com API FastAPI e banco de dados PostgreSQL.

## Tecnologias

- React
- TypeScript
- Vite
- Fetch API

## Funcionalidades

- Listagem de usuários do banco de dados
- Criação de usuários via formulário
- Exclusão de usuários
- Integração com API FastAPI

## Como rodar

1. Clone o repositório
2. Instale as dependências
```bash
npm install
```
3. Rode o projeto
```bash
npm run dev
```
4. Acesse em `http://localhost:5173`

## Requisitos

O backend FastAPI precisa estar rodando em `http://localhost:8000`.

Repositório do backend: [fastapi](https://github.com/JoaoJesus00/fastapi)
